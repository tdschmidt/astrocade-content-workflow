The system should preserve each reel as an audiovisual style reference with `music_title: null`, `music_artist: null`, `identification_status: "unverified"`, and `source_platform_audio_label: "Original audio"`. Only change those fields after obtaining a creator credit, a platform attribution identifying the recording, or a reviewed audio-recognition match. Genre resemblance, comment jokes, and a familiar-sounding beat are insufficient evidence.

The experiment's original synthesized soundtrack can test the observed edit rhythm, but it should remain labeled as demonstration audio rather than the reference reel's song.
