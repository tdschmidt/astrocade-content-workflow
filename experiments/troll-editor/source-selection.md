The initial Crowd/Golem nominations were reconsidered after the user asked whether Crowd Pier Run was actually suitable and supplied juke/revenge references. This comparison uses original recordings and newly viewed source contact sheets, plus the existing dense analyses for candidate windows. Contact sheets live in `data/experiments/troll-editor/evidence/`. The selection is an editorial judgment, not an audience-performance claim.
